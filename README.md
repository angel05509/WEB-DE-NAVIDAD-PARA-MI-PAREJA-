# 🎄 Libro de Aventuras: Nuestra Navidad — 2026

Un refugio virtual donde el tiempo se detiene para revivir nuestra historia. He preparado este rincón especial para celebrarte esta Navidad, porque ni los kilómetros ni la distancia pueden apagar lo que sentimos. Un recorrido por nuestros mejores recuerdos para hacerte sentir mi abrazo y mi presencia en cada segundo de este día.

> *"Una cápsula digital del tiempo creada para celebrar nuestro camino juntos. Aunque esta Navidad nos encuentre en lugares distintos, este espacio reúne cada risa, cada detalle y los momentos más hermosos que hemos compartido en estos meses. Es mi forma de acortar la distancia, estar a tu lado en esta fecha tan especial y recordarte cuánto te amo."*

## ✨ Características
- **Línea del Tiempo:** Recorrido cronológico por nuestros momentos más especiales durante estos meses.
- **Carta de Navidad:** Dedicatoria escrita especialmente para esta fecha.
- **Galería de Recuerdos:** Colección visual con nuestras fotos favoritas.
- **Diseño Responsivo:** Adaptado para verse perfectamente desde el celular o computadora.

## 🛠️ Tecnologías Utilizadas
- **HTML5** — Estructura semántica del sitio.
- **CSS3** — Estilos, animaciones suaves y diseño responsivo.
- **JavaScript** — Interactividad y transiciones.
- **Netlify** — Alojamiento y despliegue web.
